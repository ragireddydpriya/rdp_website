# Devi Priya Ragireddy Portfolio

Static portfolio website for GitHub Pages.

## Files

- `index.html` - page content and structure
- `styles.css` - responsive visual design
- `script.js` - small footer year script
- `assets/devi-priya-ragireddy.png` - profile photo
- `assets/DeviPriyaRagireddy.pdf` - downloadable resume

## How to Run Locally

1. Clone or download this repository to your local machine.

2. Open the project folder in your preferred code editor (e.g., VS Code).

3. **Option A: Direct Open**
   - Right-click on `index.html` and select "Open with" your browser, or
   - Double-click `index.html` to open it in your default browser.

4. **Option B: Using a Local Server** (Recommended)
   - If you have Python installed:
     ```
     python -m http.server 8000
     ```
   - If you have Node.js installed:
     ```
     npx http-server
     ```
   - Then open `http://localhost:8000` in your browser.

5. The website should now be running locally. You can make changes to `index.html`, `styles.css`, or `script.js` and refresh the browser to see updates.

## GitHub Pages

Push these files to a GitHub repository and enable GitHub Pages from the
repository settings. Use the root folder as the Pages source.
